# Разделение работы на пять человек

| Роль | Зона ответственности | Результат |
| --- | --- | --- |
| 1. Audio/ASR | FFmpeg, Faster-Whisper, тесты RU/KK/EN | точный транскрипт с таймкодами |
| 2. Diarization | pyannote, объединение интервалов, спикеры | реплики `Speaker 1..N` |
| 3. Local LLM | Ollama, Qwen3, JSON Schema, anti-hallucination | структурированный протокол |
| 4. Backend/Export | FastAPI, jobs, JSON/CSV/PDF | стабильный локальный API |
| 5. Frontend/Demo | интерфейс, UX, сценарий и презентация | готовая демонстрация |

## Правило интеграции

Каждый работает в своей `feat/*` ветке. Все ветки интегрируются в `main` только
через Pull Request после тестов. За сутки до демо новые функции замораживаются:
команда исправляет только ошибки и репетирует случайное двухминутное аудио.
