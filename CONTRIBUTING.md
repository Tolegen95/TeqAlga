# Участие в разработке

## Ветки

- `main` — только проверенная версия для демо;
- `feat/<short-name>` — новая функция;
- `fix/<short-name>` — исправление;
- `docs/<short-name>` — документация.

## Перед Pull Request

```bash
python -m pytest
ruff check app tests scripts
```

Не добавляйте в Git аудиозаписи, транскрипты встреч, модели, `.env`, токены и
содержимое папки `data/`. Для разработки используйте только синтетические примеры
с согласия участников.

## Definition of Done

1. Функция работает без коммерческого API.
2. Ошибки показываются пользователю понятным текстом.
3. Извлечённые факты имеют ссылки на сегменты транскрипта.
4. Добавлен или обновлён тест.
5. Изменение проверено с отключённым интернетом.
